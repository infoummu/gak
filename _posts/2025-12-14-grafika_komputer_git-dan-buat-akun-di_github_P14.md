## 📝 Pelajari Git dan Pembuatan Akun di GitHub


## 1. Pengantar: Mengapa Git dan GitHub Penting bagi Programmer

Seorang programmer adalah orang yang mampu menyelesaikan masalah dengan pengetahuan di bidang Pemrograman dan juga tentang membangun perangkat lunak. Untuk membangun proyek yang kompleks dan dikerjakan dalam tim, penggunaan **Version Control System (VCS)** adalah wajib.

* **Git** berfungsi sebagai **mesin waktu** yang mencatat dan mengelola setiap perubahan kode Anda, memungkinkan Anda bekerja secara paralel pada fitur yang berbeda dan kembali ke versi stabil kapan saja.
* **GitHub** adalah *platform* berbasis web yang menyediakan **repositori sentral** untuk kolaborasi kode.

Menguasai Git dan GitHub mengajarkan **disiplin kerja tim**, **manajemen risiko kode**, dan **alur kerja kolaborasi** yang menjadi standar industri, keterampilan esensial dalam pengembangan perangkat lunak skala nyata.

## 2. Tugas: Buatlah Akun di GitHub dan Projek Baru

1. **Setiap mahasiswa diwajibkan untuk membuat akun GitHub pribadi dan sebuah projek/repositori baru dan mendokumentasikan prosesnya secara lengkap dalam format PDF.**
2. **Buat projek/Repositori baru di github dan push projek baru atau yang sudah anda kerjakan**
3. **Kata kunci**: 
    - **"Cara buat akun di github"**, lihat bagian A. atau cari di internet dengan kata kunci ini.
    - **"Cara buat projek baru atau repositori baru di github"**, silahkan cari di internet dengan kata kunci ini atau semisalnya.

### A. Langkah-Langkah Teknis

1.  Akses situs web **GitHub** di **`https://github.com/`**, atau clik **[github](https://github.com/){:target="_blank"}**.
2.  Lakukan proses pendaftaran akun baru (*Sign Up*) menggunakan *email* aktif Anda.
3.  Pilih *username* yang profesional dan mudah diidentifikasi (disarankan menggunakan nama asli atau kombinasinya, cth: `nama-anda-npm`).
4.  Lengkapi semua langkah verifikasi hingga akun Anda berhasil dibuat dan Anda berada di *dashboard* utama.
5.  **Ambil *screenshot*** untuk setiap langkah penting (pendaftaran, verifikasi *email*, dan *dashboard* akhir).
6.  Pada akun yang sudah jadi, jelaskan secara singkat di bagian mana Anda akan melihat *repository* yang nantinya akan digunakan untuk tugas MK.
7. Setelah selesai buat akun dan projek/repositori baru, copy **`LINK`**-nya ke halaman Absen dan upload file, **contoh** link projek github saya : **`https://github.com/infoummu/Projek1`**

### B. Dokumentasi Laporan (Format PDF)

1. **Dokumentasikan seluruh proses Buat Akun dan Repositori Baru di atas dalam bentuk berkas PDF dengan struktur berikut dibawah:**

* **Halaman 1 (Halaman Profil WAJIB):**
    * Nama Lengkap:
    * Nomor Pokok Mahasiswa (NPM):
    * Mata Kuliah: Grafika Komputer
    * Dosen Pengampu: (Isi Nama Dosen Anda)
* **Halaman Selanjutnya (Isi Laporan):**
    * Judul: Dokumentasi Pembuatan Akun GitHub dan Projek.
    * Sertakan *screenshot* yang jelas untuk setiap langkah, diikuti dengan deskripsi singkat yang menjelaskan aksi yang dilakukan pada langkah tersebut.
    * Pastikan *screenshot* menampilkan *username* GitHub yang Anda buat.
    * Dokumentasi untuk projeknya atau how-to (cara menggunakan/menjalankan projek anda) tulis di file README.md.
