### Tugas Praktikum10 Pertemuan 12 GAK INFO1:
1. Buat Projek Game Sederhana yang Isinya terdiri dari: 
	1. Gamenya Mempunyai Alur Cerita
	2. Minimal terdiri dari 3 Gambar, 1 Gambar Backround dan 2 gambar lain untuk objek diatas background
	3. Gambar Objek bisa digeraakkan dengan keyboard 
2. File code-nya berikan nama `"praktikum10_nama_game_npm.py"`, ganti **'nama_game'** sesuai dengan temanya
4. Total file yang akan di-UPLOAD adalah MINIMAL 4 File (1 File code dan 3 file gambar)
5. **Projek Game `TIDAK BOLEH SAMA`, (PROJEK YANG SAMA, yang upload TERAKHIR TIDAK DI-ABSEN)**
6. **Kumpul hari Ini, batas sampai jam 23.50**
7. LINK untuk UPLOAD TUGAS: **[https://gak.tifor.info/](https://gak.tifor.info/){:target="_blank"}**
